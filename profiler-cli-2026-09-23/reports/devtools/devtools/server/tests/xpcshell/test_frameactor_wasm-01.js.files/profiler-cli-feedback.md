# profiler-cli feedback (test_frameactor_wasm-01.js)

- **Question: "at what exact time did this marker start, to the millisecond?"** In a 3m37s profile, `thread markers --search test_frameactor_wasm-01 --list --limit 0` prints `t=2m13s`, and `marker info m-1` prints `Time: 2m13s - 2m58s (45.043s)`. I needed ms precision to say the test gave up 36 ms after starting and 1.5 s after the first launch failure. Workaround: `--list --json | python3` reading `start`. Expected: `marker info` to give the start to the ms, e.g. `2m13.147s`.
- **Question: "how many markers matching X started before and after time T?"** For example, TIMEOUT `test` markers before and after the first `Failed to launch` marker. Command: `thread markers --search TIMEOUT --list --limit 0 --json | python3 ...`. The default output only gives a count ("N markers (filtered from M)"), plus a list truncated at 5 or cut to whole seconds. Workaround: zoom push to each side would work but needs the ms time from the question above.
