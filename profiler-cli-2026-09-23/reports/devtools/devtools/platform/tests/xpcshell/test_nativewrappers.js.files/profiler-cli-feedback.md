## Which xpcshell slot each test used, and which processes each device `ps` listed
- Question: in an Android xpcshell resource-usage profile, which `XpcshellTestRunnerService$iN` slot did each test launch in, and did the `get_process_list` DEBUG markers around the failure list `:xpcshellN`?
- Commands: `profiler-cli thread markers --search "name:INFO" --list --limit 0 --json` and `--search get_process_list --list --limit 0 --json`, then a Python script. The script regex-matched the slot and `_TEST_NAME` out of the `launch_application` messages, and `ast.literal_eval`'d the process lists.
- The default `--list` output did give the messages, but each `launch_application` line is a ~3 KB command line, and each `get_process_list` line is a ~350-entry Python list. Neither is readable enough to answer the question. This is harness payload parsing, so it may be out of scope for the tool. A `--field message --grep <regex>` style extraction on list output would have covered it without a script.
